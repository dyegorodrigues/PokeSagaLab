# SPRITECOLLAB_FORMAT_NOTES.md
- Estrutura de pastas: `sprite/<id>/AnimData.xml`, `sprite/<id>/<name>-Anim.png`, `sprite/<id>/<name>-Offsets.png`, `sprite/<id>/Shadow.png`.
- AnimData.xml define: `ShadowSize`, `FrameWidth`, `FrameHeight`, `Anims -> Anim -> Name, Index, FrameWidth, FrameHeight, Durations -> Duration`.
- Mapeamento de Direções: tipicamente 8 direções (0: Sul, 1: Sudoeste, 2: Oeste, 3: Noroeste, 4: Norte, 5: Nordeste, 6: Leste, 7: Sudeste).
